Cours

1. Les intervalles de ℝ

Un intervalle est un ensemble de nombres réels vérifiant une ou deux inégalités. Il se représente par une partie continue de la droite réelle.

ℝ = ]−∞ ; +∞[.

2. Intervalles bornés

Lecture des crochets : une borne est incluse lorsque l’inégalité comporte ≤ ou ≥ ; elle est exclue lorsque l’inégalité comporte < ou >.

Exemple : ]−1 ; 3]

]−1 ; 3] est l’ensemble des réels x tels que −1 < x ≤ 3.

Donc −1 ∉ ]−1 ; 3] et 3 ∈ ]−1 ; 3].

Lecture graphique : la partie bleue représente tous les nombres compris entre −1 et 3. Le crochet est ouvert en −1 et fermé en 3.

3. Intervalles non bornés

Attention : +∞ et −∞ ne sont pas des nombres réels. Ils ne peuvent jamais être inclus : le crochet est toujours ouvert du côté de l’infini.

4. Passer d’une inégalité à un intervalle

  1. Repérer la ou les bornes.
  2. Déterminer si chaque borne est incluse ou exclue.
  3. Écrire les crochets et vérifier le côté de l’infini.
  4. Contrôler la traduction sur une droite graduée.

−2 ≤ x < 5 ⇔ x ∈ [−2 ; 5[

x > 3 ⇔ x ∈ ]3 ; +∞[

x ≤ −1 ⇔ x ∈ ]−∞ ; −1]

5. Passer d’un intervalle à une inégalité

x ∈ ]−4 ; 2] ⇔ −4 < x ≤ 2

x ∈ [1 ; +∞[ ⇔ x ≥ 1

x ∈ ]−∞ ; 7[ ⇔ x < 7

6. Tester une appartenance

Pour savoir si un réel appartient à un intervalle, on vérifie l’inégalité correspondante.

2 ∈ [−1 ; 2], car −1 ≤ 2 ≤ 2 ; mais 2 ∉ [−1 ; 2[, car la borne 2 est exclue.

À ne pas confondre : un nombre appartient à un intervalle (∈), tandis qu’un intervalle est inclus dans ℝ (⊂).

7. Intersection et réunion d’intervalles

Soient les intervalles A = [−3 ; 2] et B = [0 ; 5[.

Intersection

L’intersection de A et B, notée A ∩ B, contient les nombres qui appartiennent à la fois à A et à B.

La partie commune aux deux intervalles va de 0 à 2, bornes comprises :

A ∩ B = [0 ; 2].

Réunion

La réunion de A et B, notée A ∪ B, contient les nombres qui appartiennent à A ou à B, éventuellement aux deux.

Comme les deux intervalles se recouvrent, leur réunion forme un seul intervalle :

A ∪ B = [−3 ; 5[.

À retenir :

∩ signifie « et » : on conserve uniquement la partie commune.

∪ signifie « ou » : on rassemble toutes les valeurs des deux intervalles.

Exemple avec deux intervalles disjoints

Si C = [−4 ; −2] et D = [1 ; 3], alors C et D n’ont aucune valeur commune.

C ∩ D = ∅ et C ∪ D = [−4 ; −2] ∪ [1 ; 3].

Dans ce cas, la réunion ne peut pas s’écrire sous la forme d’un seul intervalle.

8. Valeur absolue et distance

La valeur absolue d’un réel a, notée |a|, est sa distance à 0 sur la droite réelle.

|5| = 5 ; |−3| = 3 ; |0| = 0.

La distance entre deux réels a et b est |a − b|, et |a − b| = |b − a|.

Exemple : la distance entre −3 et 5 vaut |5 − (−3)| = 8.

9. Caractériser un intervalle par une distance

Pour r ≥ 0 :

|x − a| ≤ r ⇔ a − r ≤ x ≤ a + r ⇔ x ∈ [a − r ; a + r]

L’intervalle [a − r ; a + r] a pour centre a, pour rayon r et pour amplitude 2r.

Exemple

|x − 2| ≤ 4 ⇔ −4 ≤ x − 2 ≤ 4 ⇔ −2 ≤ x ≤ 6.

L’ensemble des solutions est [−2 ; 6] : centre 2, rayon 4, amplitude 8.

Exercices

Exercice 1 — Traduire

  1. Écrire sous forme d’intervalle : −3 ≤ x < 4.
  2. Écrire sous forme d’intervalle : x > 5.
  3. Écrire sous forme d’inégalité : x ∈ ]−2 ; 7].
  4. Écrire sous forme d’inégalité : x ∈ ]−∞ ; 6[.

Exercice 2 — Appartenance

Compléter par ∈ ou ∉ :

  1. 5 … ]1 ; 5]
  2. 1 … ]1 ; 5]
  3. −2 … [−2 ; 3[
  4. 3 … [−2 ; 3[

Exercice 3 — Distance et intervalle

  1. Calculer |−7| puis la distance entre −2 et 5.
  2. Résoudre |x − 3| ≤ 2 et donner l’intervalle obtenu.
  3. Donner le centre, le rayon et l’amplitude de [−4 ; 8].

Exercice 4 — Intersection et réunion

On considère I = [−2 ; 4] et J = ]1 ; 6[.

  1. Déterminer I ∩ J.
  2. Déterminer I ∪ J.
  3. Représenter les deux résultats sur une droite graduée.

Vidéo

Vidéo explicative sur les intervalles :

À retenir

≤ ou ≥ : la borne est incluse. < ou > : la borne est exclue.

Du côté de +∞ ou −∞, le crochet est toujours ouvert.

∩ correspond à la partie commune ; ∪ rassemble les valeurs des deux intervalles.

|x − a| se lit comme la distance entre x et a.
