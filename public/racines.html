Racines carrées

Comprendre la racine carrée d'un réel positif, simplifier des écritures, effectuer des calculs exacts et résoudre une équation de la forme x² = a.

Cours Méthodes Exercices Vidéo

Cours

1. Définition

Pour tout réel a ≥ 0, la racine carrée de a, notée √a, est l'unique réel positif ou nul dont le carré vaut a.

√a ≥ 0 et (√a)² = a.

Dans l'ensemble des nombres réels, √a est définie uniquement lorsque a ≥ 0.

Exemples

√49 = 7, car 7² = 49.

√0 = 0 et √(25/9) = 5/3.

√(−4) n'est pas définie dans ℝ.

2. La relation fondamentale

Pour tout réel a :

√(a²) = |a|

La racine carrée désigne toujours un nombre positif ou nul. Il faut donc prendre la valeur absolue de a.

Exemples

√(7²) = 7

√((−7)²) = 7

√((x − 3)²) = |x − 3|

À ne pas confondre : (√a)² = a pour a ≥ 0, tandis que √(a²) = |a| pour tout réel a.

3. Produit et quotient de racines

Pour a ≥ 0 et b ≥ 0 :

√(ab) = √a × √b

Pour a ≥ 0 et b > 0 :

√(a/b) = √a/√b

Attention : en général, √(a + b) ≠ √a + √b.

Par exemple, √(9 + 16) = 5, alors que √9 + √16 = 7.

4. Pourquoi la formule du produit est-elle vraie ?

Pour a ≥ 0 et b ≥ 0, les nombres √(ab) et √a × √b sont positifs ou nuls.

(√a × √b)² = (√a)² × (√b)² = ab

Par unicité de la racine carrée positive de ab, on obtient √(ab) = √a × √b.

5. Extraire un carré parfait

Pour simplifier √n :

  1. écrire n = a²b, avec le plus grand carré parfait possible ;
  2. utiliser √(a²b) = √(a²) × √b = a√b lorsque a ≥ 0 ;
  3. vérifier que b ne contient plus de facteur carré.

Exemples

√72 = √(36 × 2) = 6√2

√180 = √(36 × 5) = 6√5

3√50 − 2√8 = 3 × 5√2 − 2 × 2√2 = 11√2

6. Effectuer des calculs exacts

On additionne ou soustrait seulement des termes comportant la même racine simplifiée.

4√3 + 7√3 = 11√3

√2 + √3 ne se réduit pas.

Pour un produit : (2√5)(3√10) = 6√50 = 30√2.

7. Valeur exacte et valeur approchée

L'écriture 3√5 est exacte. Une calculatrice donne 3√5 ≈ 6,708. Le symbole = ne doit pas remplacer ≈.

Contrôle rapide : une racine carrée est positive ou nulle. Si 0 ≤ a < b, alors √a < √b.

Comme 49 < 53 < 64, on a 7 < √53 < 8.

8. Résoudre une équation de la forme x² = a

  • si a < 0, l'équation n'a aucune solution réelle ;
  • si a = 0, l'unique solution est x = 0 ;
  • si a > 0, les solutions sont x = −√a et x = √a.

Exemples

x² = 25 donne x = −5 ou x = 5.

x² = 7 donne x = −√7 ou x = √7.

x² = −3 n'a aucune solution réelle.

Exercices

Exercice 1 — Définition et existence

Calculer lorsque l'écriture est définie dans ℝ :

  • √81
  • √0
  • √(−16)
  • √(49/25)

Exercice 2 — Racine d'un carré

Simplifier :

  • √(12²)
  • √((−9)²)
  • √((x + 4)²)
  • √((2x − 1)²)

Exercice 3 — Produit et quotient

Calculer ou simplifier :

  • √3 × √12
  • √(16 × 5)
  • √(100/9)
  • √75/√3

Exercice 4 — Extraire un carré parfait

Écrire sous la forme a√b, avec b le plus petit possible :

  • √8
  • √45
  • √98
  • √200

Exercice 5 — Réduire

Simplifier puis réduire :

  • √20 + √45
  • 3√12 − √27
  • 2√50 + 5√8

Exercice 6 — Produits

Calculer et donner une valeur exacte simplifiée :

  • (2√3)(5√6)
  • (3√2)²
  • (√5 + 2)(√5 − 2)

Exercice 7 — Exact ou approché ?

  1. Donner la valeur exacte de 2√7.
  2. En donner une valeur approchée au centième.
  3. Encadrer √30 entre deux entiers consécutifs.

Exercice 8 — Équations

Résoudre dans ℝ :

  • x² = 36
  • x² = 11
  • x² = 0
  • x² = −5

À retenir

(√a)² = a pour a ≥ 0.

√(a²) = |a| pour tout réel a.

Pour simplifier une racine, extrais le plus grand carré parfait possible. Pour additionner, commence toujours par simplifier les racines.
