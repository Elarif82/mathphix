Les ensembles de nombres

Dans ce chapitre, tu vas apprendre à organiser les nombres dans les principaux ensembles, à classer et justifier leur nature, puis à repérer, comparer, encadrer et arrondir des nombres réels.

Cours

1. Les ensembles de nombres

Les ensembles permettent de regrouper les nombres selon leurs propriétés. Un même nombre peut appartenir à plusieurs ensembles : on cherche souvent le plus petit ensemble qui le contient.

1.1 Entiers naturels et entiers relatifs

ℕ est l’ensemble des entiers naturels : ℕ = {0 ; 1 ; 2 ; 3 ; …}.

ℤ est l’ensemble des entiers relatifs : ℤ = {… ; -2 ; -1 ; 0 ; 1 ; 2 ; …}.

Convention : 0 ∈ ℕ.

1.2 Nombres décimaux : 𝔻

Un nombre est décimal lorsqu’il possède une écriture décimale finie. De façon équivalente, il peut s’écrire a / 10n avec a ∈ ℤ et n ∈ ℕ.

Exemples : -2,67 ∈ 𝔻 ; 5 = 5,0 ∈ 𝔻 ; 1/2 = 0,5 ∈ 𝔻.

En revanche, 1/3 = 0,333… n’a pas d’écriture décimale finie : 1/3 ∉ 𝔻.

1.3 Nombres rationnels : ℚ

Un nombre est rationnel lorsqu’il peut s’écrire a / b avec a ∈ ℤ, b ∈ ℤ et b ≠ 0.

Exemples : -3 = -3/1 ∈ ℚ ; 4,79 = 479/100 ∈ ℚ ; 1/3 ∈ ℚ.

Tout nombre décimal est donc rationnel.

1.4 Nombres irrationnels et nombres réels

Un nombre réel qui n’est pas rationnel est dit irrationnel. Par exemple, √2 et π sont irrationnels.

L’ensemble de tous les nombres rationnels et irrationnels est l’ensemble des nombres réels, noté ℝ.

Inclusions à retenir : ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ.

Le symbole ∈ relie un nombre à un ensemble (-2 ∈ ℤ) ; le symbole ⊂ relie deux ensembles (ℤ ⊂ 𝔻).

2. Classer un nombre dans le plus petit ensemble

Méthode :

  1. Calculer ou simplifier l’écriture donnée.
  2. Tester les ensembles du plus petit au plus grand : ℕ, puis ℤ, puis 𝔻, puis ℚ, puis ℝ.
  3. Justifier par une propriété de l’écriture obtenue.

2.1 Pourquoi 1/3 n’est-il pas décimal ?

Supposons que 1/3 soit décimal. Il existerait a ∈ ℤ et n ∈ ℕ tels que 1/3 = a/10n. On aurait alors 10n = 3a.

Ainsi 10n serait divisible par 3. Or la somme de ses chiffres vaut 1, donc il n’est pas divisible par 3 : contradiction. Ainsi 1/3 ∉ 𝔻, mais 1/3 ∈ ℚ.

2.2 Pourquoi √2 est-il irrationnel ?

Raisonnons par contradiction. Supposons √2 = p/q, avec p et q entiers, q ≠ 0, et la fraction irréductible.

Alors p² = 2q². Donc p² est pair, donc p est pair. En écrivant p = 2k, on obtient q² = 2k² : q est lui aussi pair. La fraction serait donc simplifiable par 2, contradiction. Ainsi √2 ∉ ℚ.

Attention : la calculatrice ne donne qu’une valeur approchée de √2 ou de π, jamais leur écriture exacte complète.

Application flash

Donner le plus petit ensemble contenant chacun des nombres : -8 ; 15/3 ; -7/4 ; 5/6 ; √81 ; √10.

Afficher la correction

ℤ ; ℕ ; 𝔻 ; ℚ ; ℕ ; ℝ.

3. La droite des nombres réels

À chaque point d’une droite graduée correspond un unique nombre réel, appelé son abscisse. Réciproquement, chaque nombre réel est l’abscisse d’un unique point de la droite.

Sur une droite orientée vers la droite, le plus petit nombre est situé le plus à gauche. Ainsi : -√2 < 0 < 3/2 < π.

3.1 Encadrement décimal

Encadrer un réel x consiste à trouver deux nombres a et b tels que a < x < b (ou a ≤ x ≤ b).

L’amplitude de l’encadrement est b - a.

Exemples : 1,4 < √2 < 1,5 est d’amplitude 0,1 = 10-1 ; 1,414 < √2 < 1,415 est d’amplitude 0,001 = 10-3.

Pour tout entier n ≥ 0, on peut rechercher un encadrement décimal d’amplitude 10-n, notamment par balayage à la calculatrice ou avec un programme.

3.2 Arrondir avec une précision adaptée

  1. Repérer le premier chiffre non nul : c’est le premier chiffre significatif.
  2. Conserver le nombre de chiffres significatifs demandé ou pertinent.
  3. Observer le chiffre suivant pour effectuer l’arrondi.
  4. Conserver l’unité et vérifier l’ordre de grandeur.

Exemples : 12,478 m ≈ 12,5 m au dixième ; 0,003 846 ≈ 0,003 8 avec deux chiffres significatifs.

Dans un problème, la précision choisie doit rester cohérente avec les données et avec l’usage du résultat.

Astuce

Pour retenir l’ordre des ensembles, pense à des boîtes emboîtées :

ℕ ⊂ ℤ ⊂ 𝔻 ⊂ ℚ ⊂ ℝ

Chaque ensemble contient le précédent.

Retenir : rationnels + irrationnels = réels.

Donc un nombre réel n’est pas forcément rationnel.

Quand on te demande l’ensemble le plus précis, choisis le plus petit ensemble dans lequel le nombre se trouve.
