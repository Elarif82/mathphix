Applications de Python en mathématiques

En seconde, l’algorithmique est travaillée dans tous les domaines des mathématiques. Python sert à expérimenter, calculer, représenter, simuler, conjecturer et vérifier, sans remplacer le raisonnement ni la démonstration.

Cours

1. Information chiffrée : appliquer une évolution

Pour augmenter une valeur de t %, on la multiplie par 1 + t / 100. La fonction suivante peut traiter une hausse ou une baisse. 

def valeur_finale(valeur, taux):
    return valeur * (1 + taux / 100)

print(valeur_finale(80, 15))
print(valeur_finale(80, -15))

Le premier appel renvoie 92. Le second modélise une baisse de 15 %.

2. Fonctions : calculer des images

Une fonction Python peut traduire une fonction mathématique. On peut ensuite produire un tableau de valeurs. 

def f(x):
    return x ** 2 - 3 * x + 2

for x in range(-2, 5):
    print(x, f(x))

Le programme affiche les images des entiers de −2 à 4. Ces valeurs peuvent aider à conjecturer des variations ou des extremums, qui doivent ensuite être justifiés.

3. Algèbre : chercher une valeur approchée

Une boucle while permet d’obtenir un encadrement de √2 par balayage.

x = 1.0
pas = 0.01

while (x + pas) ** 2 <= 2:
    x = x + pas

print(x, x + pas)

Le programme donne deux centièmes consécutifs qui encadrent √2. Diminuer le pas améliore la précision, mais augmente le nombre d’itérations.

4. Géométrie repérée : tester un alignement

Les points A, B et C sont alignés si les vecteurs AB et AC sont colinéaires, c’est-à-dire si leur déterminant est nul. 

def sont_alignes(xA, yA, xB, yB, xC, yC):
    determinant = (xB - xA) * (yC - yA) \
                  - (yB - yA) * (xC - xA)
    return determinant == 0

print(sont_alignes(0, 1, 2, 5, 3, 7))

La fonction renvoie un booléen : True si les trois points sont alignés et False sinon.

5. Statistiques : calculer une moyenne

Le programme suivant calcule une moyenne à partir d’une série de valeurs. Les listes sont utilisées ici comme support ; leur connaissance détaillée n’est pas exigible en seconde. 

def moyenne(valeurs):
    total = 0
    for valeur in valeurs:
        total = total + valeur
    return total / len(valeurs)

donnees = [8, 10, 12, 14, 16]
print(moyenne(donnees))

Lire un programme calculant une moyenne ou un écart type fait partie des capacités attendues, même si l’écriture complète avec des listes n’est pas exigée.

6. Probabilités : simuler une expérience aléatoire

Une fonction peut renvoyer le résultat numérique d’une expérience aléatoire. La répétition permet d’observer la fluctuation d’une fréquence. 

from random import randint

def lancer_de():
    return randint(1, 6)

def frequence_six(n):
    succes = 0
    for i in range(n):
        if lancer_de() == 6:
            succes = succes + 1
    return succes / n

print(frequence_six(1000))

Le résultat varie d’une exécution à l’autre et tend à se rapprocher de 1/6 lorsque le nombre de lancers augmente.

Méthode : passer des mathématiques au programme

1. Identifier les données et le résultat attendu. 2. Décrire l’algorithme en langage naturel. 3. Choisir les variables, conditions, boucles et fonctions. 4. Traduire en Python. 5. Tester sur des cas simples. 6. Interpréter le résultat dans le contexte du problème.

Exercices d’entraînement

Exercice 1 — Pourcentages

Utiliser puis modifier valeur_finale pour calculer le prix d’un article de 120 € après une remise de 25 %. Vérifier le résultat par un calcul.

Exercice 2 — Tableau de valeurs

Écrire une fonction correspondant à g(x) = 3x − 4, puis afficher g(x) pour tous les entiers de −5 à 5.

Exercice 3 — Encadrement

Modifier le programme d’encadrement afin d’obtenir deux millièmes consécutifs qui encadrent √5. Expliquer les deux changements effectués.

Exercice 4 — Géométrie

Utiliser la fonction sont_alignes avec A(1 ; 2), B(3 ; 5) et C(7 ; 11), puis contrôler le résultat à l’aide d’un calcul de déterminant.

Exercice 5 — Lire et modifier

Expliquer le rôle des variables total et valeur dans la fonction moyenne. Modifier les données, puis prévoir le résultat avant d’exécuter le programme.

Exercice 6 — Simulation

Modifier frequence_six pour estimer la fréquence d’obtention d’un nombre pair. Comparer les résultats pour 20, 200 puis 2 000 lancers.

Exercice 7 — Défi de programmation

Écrire une fonction qui renvoie le nombre de lancers nécessaires pour obtenir un premier 6. Répéter plusieurs fois l’expérience et commenter les résultats.

À retenir

Un résultat numérique n’est pas une preuve. Il peut suggérer une conjecture, fournir une approximation ou vérifier un cas, mais il faut toujours revenir au sens mathématique du problème.

Tester systématiquement les cas limites, contrôler les types des variables et vérifier la cohérence du résultat font partie du travail de programmation.
