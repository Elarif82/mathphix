Équations

Résoudre, vérifier et modéliser : apprends à résoudre une équation du premier degré, une équation produit nul et des équations se ramenant à ces formes.

Premier degré Produit nul Factorisation Modélisation

1. Équations et solutions

Définition

Une équation est une égalité contenant une ou plusieurs inconnues. Résoudre une équation consiste à déterminer toutes les valeurs de l’inconnue qui rendent l’égalité vraie.

Dans 2x + 3 = 11, le nombre 4 est une solution, car 2 × 4 + 3 = 11.

Équations équivalentes

Deux équations sont équivalentes lorsqu’elles ont exactement les mêmes solutions.

Pour transformer une équation en une équation équivalente, on peut :

  • ajouter ou soustraire un même nombre aux deux membres ;
  • multiplier ou diviser les deux membres par un même nombre non nul ;
  • développer, réduire ou factoriser une expression sans en changer la valeur.

Vocabulaire : dans une égalité, les expressions situées à gauche et à droite du signe égal sont appelées les deux membres.

2. Équations du premier degré

Méthode

Pour résoudre une équation du type ax + b = cx + d :

  1. développer et réduire chaque membre si nécessaire ;
  2. regrouper les termes contenant x dans un même membre ;
  3. regrouper les nombres dans l’autre membre ;
  4. diviser par le coefficient de x, s’il est non nul ;
  5. vérifier la valeur obtenue dans l’équation de départ.

Exemple détaillé

Résoudre dans ℝ : 5x + 16 = 8x + 7.

5x + 16 = 8x + 7

5x - 8x = 7 - 16

-3x = -9

x = 3

Vérification : 5 × 3 + 16 = 31 et 8 × 3 + 7 = 31. Donc S = {3}.

Exemple avec développement

Résoudre : 3(2x - 5) = 4x + 1.

6x - 15 = 4x + 1

2x = 16

x = 8, donc S = {8}.

Cas particuliers

  • x + 2 = x + 5 conduit à 2 = 5 : aucune solution, donc S = ∅.
  • 2(x + 1) = 2x + 2 conduit à 2x + 2 = 2x + 2 : tous les réels conviennent, donc S = ℝ.

3. Équations produit nul

Propriété fondamentale

Pour tous nombres réels A et B :

A × B = 0 si et seulement si A = 0 ou B = 0.

Autrement dit, un produit est nul si et seulement si au moins l’un de ses facteurs est nul.

Exemple - Produit déjà factorisé

Résoudre : (6x - 2)(8x + 1) = 0.

D’après la propriété du produit nul :

6x - 2 = 0 ou 8x + 1 = 0.

x = 1/3 ou x = -1/8.

Donc S = {-1/8 ; 1/3}.

Condition indispensable : la propriété du produit nul s’applique seulement lorsque le produit est égal à zéro. Elle ne s’applique pas directement à (x - 2)(x + 3) = 5.

4. Se ramener à un produit nul

Méthode

  1. tout regrouper dans un même membre pour obtenir une expression égale à zéro ;
  2. factoriser l’expression ;
  3. appliquer la propriété du produit nul ;
  4. résoudre chaque équation obtenue.

Exemple - Factoriser avant de résoudre

Résoudre : 2x² - 3x = 0.

On factorise par x :

x(2x - 3) = 0.

Donc x = 0 ou 2x - 3 = 0.

x = 0 ou x = 3/2.

Ainsi, S = {0 ; 3/2}.

Exemple - Faire apparaître zéro

Résoudre : x(x + 4) = 5x.

x(x + 4) - 5x = 0

x(x - 1) = 0

Donc x = 0 ou x = 1, et S = {0 ; 1}.

5. Équations quotient

Valeurs interdites

Une expression quotient n’est définie que lorsque son dénominateur est non nul. Il faut donc déterminer les valeurs interdites avant de résoudre l’équation.

Exemple

Résoudre : (2x + 1)/(x - 3) = 4.

Condition d’existence : x ≠ 3.

Pour x ≠ 3, on multiplie par x - 3 :

2x + 1 = 4(x - 3)

2x + 1 = 4x - 12, puis 13 = 2x.

x = 13/2. Cette valeur est autorisée, donc S = {13/2}.

6. Mettre un problème en équation

Démarche

  1. choisir l’inconnue et préciser ce qu’elle représente ;
  2. traduire les informations par une équation ;
  3. résoudre l’équation ;
  4. vérifier et interpréter la solution dans le contexte.

Exemple

Un club facture 25 € d’adhésion puis 8 € par séance. Une personne a payé 121 €. On note n le nombre de séances.

25 + 8n = 121

8n = 96, donc n = 12.

La personne a participé à 12 séances.

7. Erreurs fréquentes

  • modifier un seul membre de l’équation ;
  • diviser par un nombre qui peut être nul ;
  • utiliser la propriété du produit nul lorsque le produit n’est pas égal à zéro ;
  • oublier de factoriser avant d’appliquer la propriété du produit nul ;
  • conserver une valeur interdite dans la solution d’une équation quotient ;
  • ne pas vérifier ou interpréter la solution obtenue.

Exercices d’entraînement

Exercice 1 - Automatismes

Résoudre dans ℝ :

  1. x + 7 = 15
  2. 5x - 4 = 21
  3. 3x + 8 = x - 6
  4. 4(2x - 3) = 5x + 9
Afficher la correction
  1. On soustrait 7 aux deux membres : x = 15 − 7 = 8. Donc S = {8}. Vérification : 8 + 7 = 15.
  2. On ajoute 4 aux deux membres : 5x = 25, puis on divise par 5 : x = 5. Donc S = {5}. Vérification : 5 × 5 − 4 = 21.
  3. On soustrait x puis 8 aux deux membres : 2x = −14, donc x = −7. Ainsi S = {−7}. Vérification : les deux membres valent −13.
  4. On développe : 8x − 12 = 5x + 9. On soustrait 5x puis on ajoute 12 : 3x = 21, d’où x = 7. Donc S = {7}. Vérification : les deux membres valent 44.

Exercice 2 - Vérifier et analyser

  1. Vérifier si -2 est solution de 3x + 4 = -2.
  2. Déterminer si 2x + 5 = 2x - 1 possède une solution.
  3. Déterminer l’ensemble des solutions de 3(x + 2) = 3x + 6.
Afficher la correction
  1. Pour x = −2, 3 × (−2) + 4 = −6 + 4 = −2. L’égalité est vraie : −2 est solution.
  2. En soustrayant 2x aux deux membres, on obtient 5 = −1. Cette égalité est fausse pour toute valeur de x. Donc S = ∅.
  3. Après développement, l’équation devient 3x + 6 = 3x + 6. L’égalité est vraie pour tout réel x : S = ℝ.

Exercice 3 - Produit nul

Résoudre :

  1. (x - 4)(x + 7) = 0
  2. (3x + 6)(5x - 1) = 0
  3. x² - 9x = 0
  4. 4x² - 12x = 0
Afficher la correction
  1. Un produit est nul si au moins un facteur est nul : x − 4 = 0 ou x + 7 = 0. Donc S = {−7 ; 4}.
  2. 3x + 6 = 0 ou 5x − 1 = 0, soit x = −2 ou x = 1/5. Donc S = {−2 ; 1/5}.
  3. On factorise par x : x(x − 9) = 0. Donc x = 0 ou x = 9, et S = {0 ; 9}. Il ne faut pas diviser par x : on perdrait la solution 0.
  4. On factorise : 4x(x − 3) = 0. Comme 4 est non nul, on obtient x = 0 ou x = 3. Donc S = {0 ; 3}.

Exercice 4 - Équations quotient

Déterminer d’abord la valeur interdite, puis résoudre :

  1. (x + 5)/(x - 2) = 3
  2. (4x - 1)/(x + 3) = 2
Afficher la correction
  1. Le dénominateur impose x ≠ 2. Pour x différent de 2, on multiplie par x − 2 : x + 5 = 3(x − 2), puis x + 5 = 3x − 6. Ainsi 11 = 2x, donc x = 11/2. Cette valeur est autorisée. Vérification : (21/2)/(7/2) = 3. Donc S = {11/2}.
  2. Le dénominateur impose x ≠ −3. Pour x différent de −3, on multiplie par x + 3 : 4x − 1 = 2(x + 3), puis 4x − 1 = 2x + 6. Donc 2x = 7 et x = 7/2. Cette valeur est autorisée. Vérification : 13/(13/2) = 2. Donc S = {7/2}.

Exercice 5 - Modélisation

Un service de location facture 18 € de frais fixes et 6 € par heure. La facture s’élève à 72 €. Choisir une inconnue, mettre la situation en équation, résoudre puis interpréter le résultat.

Afficher la correction
  1. Choix de l’inconnue : on note h la durée de location en heures, avec h ≥ 0.
  2. Mise en équation : les 18 € de frais fixes s’ajoutent au prix de la durée, soit 18 + 6h = 72.
  3. Résolution : on soustrait 18, ce qui donne 6h = 54, puis on divise par 6 : h = 9.
  4. Vérification et interprétation : 18 + 6 × 9 = 72. La durée est positive et satisfait la facture : la location a duré 9 heures.

À retenir

Isole l’inconnue par transformations équivalentes et vérifie toujours la solution dans l’équation de départ.

Pour une équation produit, fais d’abord apparaître un produit égal à zéro.

Pour une équation quotient, commence par exclure les valeurs qui annulent le dénominateur.
