Les bases de Python

Cette page présente les notions de Python attendues en seconde : variables et types, affectation, séquences d’instructions, conditions, boucles for et while, puis fonctions. L’objectif est aussi de savoir lire, expliquer, compléter et modifier un programme.

Cours

1. Variables, types et affectation

Une variable mémorise une valeur. L’instruction a = 5 affecte la valeur 5 à la variable a : le signe = ne représente donc pas ici une égalité mathématique. 

nombre = 5           # entier : int
mesure = 2.5         # flottant : float
message = "Bonjour"  # chaîne de caractères : str
test = nombre > 0    # booléen : bool

nombre = nombre + 1
print(nombre)

Après la dernière affectation, nombre vaut 6. Python exécute les instructions dans l’ordre où elles sont écrites.

2. Entrées, sorties et calculs

input() lit une réponse sous forme de texte. On utilise int() ou float() lorsqu’un calcul numérique est attendu. 

prix = float(input("Prix en euros : "))
taux = 20
prix_final = prix * (1 + taux / 100)
print("Prix final :", prix_final)

Les opérateurs usuels sont +, -, *, / et ** pour une puissance.

3. Conditions et booléens

Une condition est une expression qui vaut True ou False. Les comparaisons s’écrivent notamment <, <=, >, >=, == et !=. 

x = float(input("x = "))

if x > 0:
    print("x est positif")
elif x == 0:
    print("x est nul")
else:
    print("x est négatif")

L’indentation délimite les instructions exécutées dans chaque cas. On peut combiner des conditions avec and, or et not.

4. Boucle bornée for

Une boucle bornée est utilisée lorsque le nombre de répétitions est connu.

for i in range(1, 6):
    print(i, i ** 2)

Ce programme affiche les carrés des entiers de 1 à 5. La borne finale de range(1, 6) n’est pas incluse.

5. Boucle non bornée while

Une boucle non bornée répète des instructions tant qu’une condition est vraie. Il faut veiller à modifier une variable pour que la condition devienne fausse. 

n = 1

while n ** 2 < 50:
    n = n + 1

print(n)

Le programme affiche 8 : c’est le plus petit entier positif dont le carré est supérieur ou égal à 50.

6. Fonctions à un ou plusieurs arguments

Une fonction reçoit des arguments et renvoie un résultat avec return. Il ne faut pas confondre renvoyer une valeur et l’afficher. 

def image_affine(x, a, b):
    return a * x + b

y = image_affine(3, 2, 1)
print(y)

L’appel image_affine(3, 2, 1) renvoie 7.

7. Lire, vérifier et modifier un programme

Avant d’exécuter le programme suivant, prévoir la valeur affichée.

def mystere(n):
    resultat = 0
    for i in range(1, n + 1):
        resultat = resultat + i
    return resultat

print(mystere(4))

On obtient 10, car le programme calcule 1 + 2 + 3 + 4. Pour contrôler un programme, on peut suivre pas à pas les valeurs des variables, tester des cas simples et vérifier la vraisemblance du résultat.

À retenir

En Python, l’indentation est essentielle : elle indique quelles instructions appartiennent à une condition, une boucle ou une fonction.

Pour passer d’un algorithme en langage naturel à Python, identifier les données, les variables, les étapes du calcul, les conditions, les répétitions et le résultat attendu.
