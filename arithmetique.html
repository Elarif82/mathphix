Arithmétique

Découvre comment reconnaître les multiples et les diviseurs, raisonner sur les nombres pairs et impairs et rendre une fraction irréductible.

Entiers Multiples Parité Fractions

1. Entiers naturels et entiers relatifs

Les ensembles ℕ et ℤ

L’ensemble ℕ contient les entiers naturels : ℕ = {0 ; 1 ; 2 ; 3 ; ...}.

L’ensemble ℤ contient les entiers relatifs : ℤ = {... ; -3 ; -2 ; -1 ; 0 ; 1 ; 2 ; 3 ; ...}.

Tout entier naturel est un entier relatif : ℕ ⊂ ℤ.

2. Multiples et diviseurs

Définition

Soient a et b deux entiers, avec b ≠ 0. On dit que a est un multiple de b s’il existe un entier k tel que :

a = k × b.

Dans ce cas, b est un diviseur de a.

Exemples

  • 21 = 7 × 3 : 21 est un multiple de 3 et 3 divise 21.
  • -20 = (-4) × 5 : -20 est un multiple de 5.
  • 11 n’est pas un multiple de 5 car aucun entier k ne vérifie 11 = 5k.

Critères utiles

  • Un entier est divisible par 2 si son chiffre des unités est 0, 2, 4, 6 ou 8.
  • Il est divisible par 3 si la somme de ses chiffres est divisible par 3.
  • Il est divisible par 5 s’il se termine par 0 ou 5.
  • Il est divisible par 9 si la somme de ses chiffres est divisible par 9.
  • Il est divisible par 10 s’il se termine par 0.

3. Somme de deux multiples

Propriété

La somme de deux multiples d’un même entier est encore un multiple de cet entier.

Démonstration pour les multiples de 7

Soient u et v deux multiples de 7. Il existe donc deux entiers k et m tels que :

u = 7k et v = 7m.

Alors :

u + v = 7k + 7m = 7(k + m).

Comme k + m est un entier, u + v est un multiple de 7.

Cette propriété concerne des multiples d’un même entier. Par exemple, 28 et 35 sont des multiples de 7, donc 63 est aussi un multiple de 7.

4. Nombres pairs et nombres impairs

Définitions

Un entier n est pair s’il existe un entier k tel que :

n = 2k.

Un entier n est impair s’il existe un entier k tel que :

n = 2k + 1.

Exemples : 42 = 2 × 21 est pair et 35 = 2 × 17 + 1 est impair.

Démonstration : le carré d’un nombre impair est impair

Soit n un entier impair. Il existe un entier k tel que :

n = 2k + 1.

Alors :

n² = (2k + 1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1.

Le nombre 2k² + 2k est entier. Ainsi, n² est de la forme 2p + 1 : il est impair.

Quelques résultats de parité

  • pair + pair = pair ;
  • impair + impair = pair ;
  • pair + impair = impair ;
  • le produit de deux nombres impairs est impair ;
  • un produit contenant un facteur pair est pair.

5. Fractions irréductibles

Définition

Deux entiers sont premiers entre eux lorsque leur seul diviseur positif commun est 1. Une fraction est irréductible lorsque son numérateur et son dénominateur sont premiers entre eux.

Exemple 1

Les diviseurs positifs de 20 sont 1, 2, 4, 5, 10, 20.

Les diviseurs positifs de 77 sont 1, 7, 11, 77.

Leur seul diviseur positif commun est 1 : la fraction 20/77 est irréductible.

Exemple 2 - Rendre une fraction irréductible

Le numérateur et le dénominateur de 84/126 sont divisibles par 42 :

84/126 = (42 × 2)/(42 × 3) = 2/3.

Comme 2 et 3 sont premiers entre eux, 2/3 est irréductible.

6. Algorithmes

Tester si un entier est un multiple d’un autre

Le reste de la division euclidienne de a par b est obtenu en Python avec a % b. Si ce reste vaut 0, alors a est un multiple de b. 

def est_multiple(a, b):
    return a % b == 0

Par exemple, est_multiple(42, 7) renvoie True.

Plus grand multiple de a inférieur ou égal à b

Pour des entiers naturels a > 0 et b :

def plus_grand_multiple(a, b):
    quotient = b // a
    return quotient * a

Par exemple, le plus grand multiple de 7 inférieur ou égal à 50 est 49.

7. Résoudre des problèmes

Répartir des objets

On veut ranger 96 cahiers dans des lots contenant tous le même nombre de cahiers, sans reste. Les tailles possibles des lots sont exactement les diviseurs de 96.

Par exemple, des lots de 8 conviennent car 96 = 12 × 8. On obtient alors 12 lots.

Raisonner avec la parité

La somme de trois entiers impairs est-elle paire ou impaire ? Écrivons-les 2a + 1, 2b + 1 et 2c + 1.

(2a + 1) + (2b + 1) + (2c + 1) = 2(a + b + c + 1) + 1.

La somme est donc impaire.
